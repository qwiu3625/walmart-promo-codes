# walmart promo code: the pickup and delivery codes worth trying, why they fail at checkout, and how to stack cashback on top

Somebody always ends up on a coupon page promising "50% off sitewide," pastes that code into Walmart's promo box, and gets nothing. The reason isn't a broken code. Walmart doesn't run a sitewide code program at all. What it does run is a small, shifting set of account-targeted offers for online grocery pickup and delivery, plus the occasional game-preorder promo. You get one code per order. Whether you qualify depends on your Walmart account, your ZIP code, and how many orders you've placed before.

So the useful question isn't "what's today's Walmart promo code." It's "which of the four or five codes circulating actually applies to my account, and does it beat the cashback I'd get for the same order." Those two things usually don't stack, and most coupon pages quietly leave that part out.

## Why your Walmart promo code keeps getting rejected

The promo box on Walmart's payment step only accepts offers Walmart has issued to your account. That's the whole gate. A code pulled from a forum or a coupon aggregator is just a string until Walmart's system recognises it as belonging to you.

The usual failure points:

**You're checking out as a guest.** Guest checkout doesn't show a promo field. You need to be signed into a Walmart account.

**You're in the app.** Some codes are website-only. If a code that "should" work does nothing, paste it into a browser checkout before giving up on it.

**Your cart doesn't qualify.** Most of these are grocery pickup and delivery offers, so alcohol and prescriptions are out, and some accounts need at least one grocery item in the basket before the discount triggers. A cart of towels and a vacuum cleaner may not count, even if it's north of $35.

**You've already used it.** FAST30 is widely reported as good for up to three orders, which is unusual. Most of the others are one-and-done or first-order-only.

**You typed two codes.** Walmart's checkout accepts one. If you paste a second, it usually just replaces the first.

And a note on the "50% off sitewide" listings: those point at existing rollbacks, clearance pricing and seasonal sales events that are already reflected in the price. There's no code to enter, and no amount of retrying will produce one. Walmart's own position is that its prices are low enough that it doesn't run a coupon program, which is why what exists lives almost entirely inside the college-grocery-delivery corner of the site.

## The stacking problem nobody flags

Here's the part that matters if you're also using a cashback portal. ShopBack's Walmart terms exclude "purchases made with vouchers or promo codes not featured on our platform" from earning cashback. Read that again: using a random code from a forum can wipe out the cashback you were counting on for the same order.

So on a $35 grocery order you're choosing between levers, not stacking them:

- **FAST30** takes $10 off the top, immediately and unconditionally.
- **The new-user cashback offer** pays a flat $8 back, but it lands as pending, clears in 75 days, and gets reversed if you return anything.

The code wins that comparison. Where the cashback wins is on orders no code covers — a Walmart+ subscription, a big electronics haul, or any order where a boosted Walmart cashback day is live at a percentage with a fat cap. On those, there's no promo code competing for the same transaction, so the cashback is pure upside.

The safe rule: don't assume they stack, and don't burn a working code chasing cashback that might not track. If both look close, take the instant discount — a pending cashback you have to wait 75 days for carries more risk than money off at checkout.
